# GPU 性能测试工具

一个基于 Python 和 FurMark2 的 GPU 能效测试工具，支持自动频率调节、功耗/温度/电压监控，并生成性能曲线图表。

## 功能特性

- 自动控制 FurMark2 进行基准测试（支持 OpenGL 和 Vulkan）
- 锁定 GPU 核心频率进行多档位测试
- 实时监控 GPU 功耗、实际频率、温度
- 解析 FurMark2 导出的 CSV 文件获取电压数据
- 输出汇总 Excel/CSV 文件及详细时序数据
- 交互式可配置图表（频率/功耗/分数/电压关系曲线）
- 完善的图形界面（配置、图表、日志、系统信息）
- 支持字体自定义、配置保存/加载
- 自动过滤异常数据（IQR 方法）

## 系统要求

- Windows 操作系统（依赖 NVML 和 GPU 锁定频率功能）
- NVIDIA GPU（需要支持 NVML 和锁定频率）
- FurMark2 已安装（可从 [Geeks3D](https://geeks3d.com/furmark/) 下载）

## 安装与依赖

### 1. 安装 Python 环境

需要 Python 3.7 或更高版本。

### 2. 安装第三方库

使用 pip 安装所需库：

```bash
pip install pandas matplotlib numpy openpyxl pynvml
```

- `pandas` – 数据处理和 Excel/CSV 导出
- `matplotlib` – 图表绘制
- `numpy` – 数值计算和异常值过滤
- `openpyxl` – Excel 文件写入（可选，不安装则自动降级为 CSV）
- `pynvml` – NVIDIA 管理库，用于频率锁定和监控

### 3. 安装 FurMark2

从官网下载并安装 FurMark2，记住可执行文件的路径（例如 `C:\FurMark\FurMark.exe`）。

## 使用方法

### 启动程序

以**管理员身份**运行程序（否则可能无法锁定 GPU 频率）：

```bash
python gputest.py
```

### 界面布局

- **测试配置**：设置 FurMark 路径、输出目录、测试参数、频率范围、FurMark 运行参数等。
- **结果图表**：选择 X/Y 轴，生成折线图或散点图，可添加趋势线。
- **测试日志**：实时显示测试过程的详细信息。
- **系统信息**：显示 GPU、驱动、显存等基础信息。

### 测试流程

1. 在“测试配置”选项卡中，设置：
   - FurMark 程序路径
   - 输出目录（测试结果保存位置）
   - 每个频率点的测试时长（秒）
   - 冷却时间（秒）
   - 采样间隔（秒）
   - 起始频率、结束频率、步进值（MHz）
   - FurMark 分辨率、MSAA、图形 API（OpenGL 或 Vulkan）
   - 高级选项（无界面、无分数框等）

2. 点击 **开始测试**。

3. 程序将：
   - 依次设置目标频率
   - 启动 FurMark2 进行压力测试
   - 在测试期间按采样间隔记录功耗、实际频率、温度
   - 测试结束后解析 FurMark2 生成的电压数据
   - 冷却指定时间后进入下一个频率点

4. 测试完成后，输出目录中将生成以下文件：
   - `gpu_performance_summary.xlsx`（或 CSV）– 各频率点的汇总数据
   - `all_frequencies_detail.csv` – 全部采样的时序数据
   - `performance_charts.png` – 预先生成的四张关系图（频率-电压、电压-功耗、频率-功耗、频率-分数）

5. 可在“结果图表”选项卡中自定义 X/Y 轴并生成图表。

### 停止测试

点击 **停止测试** 按钮，程序会在当前频率点完成后退出测试循环。

### 导出结果

点击 **导出结果** 按钮，将汇总数据、详细数据和性能图表保存到用户指定的文件。

## 配置管理

- **保存配置**：将当前所有设置（路径、参数、字体等）保存到 `.cfg` 文件。
- **加载配置**：从之前保存的配置文件恢复设置。
- **重置默认设置**：恢复程序初始默认值。

## 常见问题

### 1. 提示“NVML 初始化失败”

- 确保以**管理员身份**运行程序。
- 确认 NVIDIA 显卡驱动已安装且支持 NVML（一般专业卡和 GeForce 驱动均支持）。
- 检查是否安装了 `pynvml` 库：`pip install pynvml`

### 2. FurMark 无法启动或报告错误

- 检查 FurMark 路径是否正确，建议使用完整路径。
- 如果 FurMark 版本较旧，可能不支持 `--no-osi` 或 `--log-gpu-data` 等参数，请更新到 FurMark2。
- 命令行参数基于 FurMark2（1.x 版本）设计，旧版 FurMark 可能不兼容。

### 3. 无法锁定 GPU 频率

- 某些笔记本或节能模式可能限制频率锁定，尝试在 NVIDIA 控制面板中将电源管理模式设为“最高性能优先”。
- 确保没有其他超频工具（如 MSI Afterburner）干扰。

### 4. 电压数据为 0

- 这是正常的，因为我暂时还没找到电压怎么读取,有空会尝试解决的:(

### 5. 中文字符显示为方框

- 在“设置”→“字体设置”中选择系统支持的中文字体（如“Microsoft YaHei”或“SimHei”）。
- 程序会自动配置 matplotlib 的字体。

## 注意事项

- **需要管理员权限**：NVML 的锁定频率功能需要管理员权限。
- **测试过程 GPU 负载极高**：请确保显卡散热良好，避免过热。
- **冷却时间**：每个频率点结束后会有冷却时间，不要设置过短，否则温度累积会影响后续测试准确性。
- **步进值**：应为整数，且频率范围必须能被步进值整除，否则程序会报错。
